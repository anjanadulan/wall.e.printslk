## 🔥 What We Do

**Wall·E Prints** is a premium bespoke print studio based in **Sri Lanka**, specializing in:

- 🏎️ **Automotive Art** — JDM legends, supercars, F1 machines, and superbike posters
- 🎌 **Anime & Manga** — Demon Slayer, One Piece, Jujutsu Kaisen, and custom character prints
- 🎮 **Gaming & Pop Culture** — Cyberpunk aesthetics, character art, and setup decor
- 🖼️ **Triptych Splits** — One stunning image split across 3 A4 panels for a gallery-grade 3D wall display
- 🎨 **Bespoke Custom Designs** — Send us your own image and we'll optimize, upscale, and print it to perfection

Every print is produced in-house using a **Canon G2010** ink tank printer with manually calibrated intensity profiles for deep blacks, vibrant colors, and razor-sharp detail.

## 🌐 Website Features

This repository contains the official **Wall·E Prints** landing page and client portal — a fully interactive, premium web experience:

### ✨ Highlights

- **🎯 Interactive Room Previewer** — Swap artwork, room backgrounds, and framing styles (Standard A4 / Triptych 3-Panel) in real time
- **🎠 Coverflow Art Gallery** — Browse our signature prints in a sleek carousel with zoom popups
- **📊 Quote Calculator** — Select media finish, quantity, and customization options to get instant cost estimates
- **📱 One-Tap WhatsApp Ordering** — Every product and quote form connects directly to our WhatsApp for instant order placement
- **🔍 Order Tracking Integration** — Track your delivery status via Citypak portal
- **🌌 3D Particle Background** — WebGL-powered floating particle animation with interactive mouse parallax

### 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| **HTML5** | Semantic structure & SEO |
| **Tailwind CSS** | Utility-first responsive styling |
| **Vanilla JavaScript** | Interactive previewer, carousel, calculator logic |
| **Three.js** | WebGL 3D particle background renderer |
| **Font Awesome** | Premium icon system |
| **Google Fonts** | Montserrat, Nunito, Source Code Pro, Space Grotesk |

### 🎨 Design Philosophy

- **Glassmorphism** — Frosted glass panels with backdrop blur effects
- **Red & Black Theme** — High-contrast dark mode with crimson accents
- **Micro-Animations** — Hover effects, pulse glows, smooth transitions
- **A4 Aspect Ratio Locking** — All preview panels maintain true 1:1.414 print proportions

## 🚀 Getting Started

No build tools required — this is a static site. Just open it:

```bash
# Clone the repository
git clone https://github.com/anjanadulan/wall.e.printslk.git

# Open in browser
cd wall.e.printslk
start index.html
```

Or use a local dev server for the best experience:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
